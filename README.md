Título: SISTEMA DE CITAS MÉDICAS DE BOHÓRQUEZ, ATLÁNTICO.

Descripción: Este proyecto busca mejorar el proceso de apartado de citas medicas y su sistema interno de turno en el corregimiento de Bohorquéz atlántico. Teniendo en cuenta problematicas como ubicación, baja conectividad, perdida de señal, circunstancias expuestas por distintos estudios a nvel general en el país realizados por terceros como el DANE, ministerio de salud de Colombia, etc... Este proyecto además de ser un reto personal y una oportunidad de fortalecer mis habilidades, principalmente busca ayudar a mi comunidad a solucionar las problemáticas de largos periodos de espera, perdidas de tiempo del paciente, sobrecupo en citas o pérdida de información.
